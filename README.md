# Timetable CLI · 课程表查询工具

一个用**纯 JDK** 编写的命令行课程表查询工具：读取 CSV 课程数据，按星期 / 周次 / 关键字查看课表，查询空教室，并检测排课冲突。

- 语言：Java 17+（本仓库在 JDK 21 上开发与验证）
- 依赖：**零第三方依赖**，不使用 Maven / Gradle，`javac` + `java` 即可完成构建与运行
- 许可证：MIT
- 作者：王朋（2026）

## 1. 项目简介

每学期开学，同学们常遇到几个高频问题：这周四第 3 节到底上不上课？下周是不是换成另一门课了？周四下午哪个教室还空着？两门课是不是排在了同一个时间段？

这些问题用教务系统网页能查，但页面上信息分散、也不能批量检索。本项目把课程表抽象成一份可版本管理的 **CSV 数据文件**，用一个轻量命令行工具完成查询与校验：改课表只需改一行 CSV，查课表只需敲一条命令，输出的 ASCII 表格可以直接贴进 Markdown 笔记。

项目结构刻意保持"小而不简陋"：模型层、数据层、服务层、表现层四层分离，输入解析、周次计算、文本宽度对齐等细节都有独立实现与注释，适合作为 Java 基础语法的综合练习，也适合作为开源协作流程（Issue / PR / 版本记录）的演练项目。

## 2. 功能列表

| 命令 | 功能说明 | 状态 |
| --- | --- | --- |
| `all [周次]` | 输出整周课表网格（周一至周五，有周末课时自动扩展到周六、周日） | 已实现 |
| `current` | 按系统日期计算当前教学周，输出该周课表 | 已实现 |
| `day <星期> [周次]` | 输出某一天的详细课表（时间、教师、教室、周次、类型） | 已实现 |
| `search <关键字> [周次]` | 按课程名 / 教师 / 教室 / 课程编号模糊搜索 | 已实现 |
| `free <星期> <节次> [周次]` | 查询某个时间段内仍然空闲的教室 | 已实现 |
| `idle <星期> [周次]` | 统计某一天的空闲节次与可用教室数量 | 已实现 |
| `conflict [周次]` | 检测同一时间段的时间冲突与教室冲突 | 已实现 |
| `rooms` | 列出数据中出现过的全部教室及其占用状态 | 已实现 |
| `today` | 打印当天日期，并提示可用的课表查询入口 | 已实现 |
| `about` | 输出项目版本、作者与许可证信息 | 已实现 |
| `help` | 显示命令帮助 | 已实现 |

补充特性：

- **周次过滤**：数据里每门课都有 `start_week` / `end_week`，第 9 周查询不会再列出只在 1-8 周开设的课程。
- **半学期课切换**：同一时间段可以先后安排两门课（例如周四 1-2 节前 8 周是 Java、后 8 周是 Go），查询时按周次自动区分。
- **中文等宽对齐**：终端里汉字占两列，工具内部按显示宽度（而非 `String.length()`）计算补位，表格在任何字体下都不会错位。
- **容错输入**：星期支持 `周一 / 星期一 / 礼拜一 / 1` 四种写法，周次、节次越界会给出明确提示并以退出码 2 结束。
- **可替换数据源**：`--data <路径>` 参数可指定其它 CSV 文件，方便同学换成自己班的课表使用。

## 5. 编译与运行

### 5.1 Windows 一键运行（推荐）

双击 `run.bat`，或在该目录打开命令提示符：

```bat
run.bat              :: 编译并查看当前教学周课表
run.bat all 9        :: 编译并查看第 9 周课表
run.bat day 1        :: 编译并查看周一课表
```

只编译不运行：

```bat
build.bat
```

### 5.2 命令行手动编译（跨平台通用）

在项目根目录执行：

```bash
# 1. 创建输出目录
mkdir out

# 2. 编译：-sourcepath 让 javac 自行解析依赖，无需逐个列出源文件
javac -encoding UTF-8 -sourcepath src -d out src/timetable/Main.java

# 3. 运行
java -cp out timetable.Main all 9
```

编译成功后 `out/` 目录下会生成 13 个 `.class` 文件（11 个顶层类 + 2 个内部类）。

### 5.3 注意事项

- 命令需在**项目根目录**执行，因为默认从 `data/courses.csv` 读取数据；也可以在任何目录用 `--data` 指定绝对路径。
- Linux / macOS 终端若中文显示为方块，请确认终端为 UTF-8 且使用等宽字体（如 Sarasa Mono SC、Cascadia Mono）。
- Windows 控制台若出现乱码，先执行 `chcp 65001` 切到 UTF-8 代码页。

## 7. 数据格式说明

课程数据存放在 `data/courses.csv`，UTF-8 无 BOM 编码，以逗号分隔。以 `#` 开头的行是注释，会被解析器跳过。

### 7.1 字段定义

| 列序 | 字段名 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| 1 | `id` | 字符串 | 课程编号，唯一，重复会报错 | `C001` |
| 2 | `name` | 字符串 | 课程名称 | `数据结构` |
| 3 | `teacher` | 字符串 | 任课教师 | `李国强` |
| 4 | `room` | 字符串 | 上课教室 | `教1-201` |
| 5 | `day` | 字符串 | 星期，支持 `周一` / `星期一` / `1` | `周一` |
| 6 | `start_period` | 整数 | 开始节次（1-12） | `1` |
| 7 | `end_period` | 整数 | 结束节次（须 ≥ 开始节次） | `2` |
| 8 | `start_week` | 整数 | 起始周（1-16） | `1` |
| 9 | `end_week` | 整数 | 结束周（1-16） | `16` |
| 10 | `type` | 字符串 | 课程类型，如 `必修` / `选修` | `必修` |

表头行 `id,name,teacher,...` 建议保留：解析器会自动跳过首个非注释行（判定依据是第 6 列 `start_period` 不是整数），没有表头也能正常读取。字段顺序固定按上表的位置解析，不支持调换列的顺序。

### 7.2 示例数据

```csv
id,name,teacher,room,day,start_period,end_period,start_week,end_week,type
C001,数据结构,李国强,教1-201,周一,1,2,1,16,必修
C010,Java程序设计,周航,机房A-201,周四,1,2,1,8,必修
C011,Go语言与并发编程,周航,机房A-201,周四,1,2,9,16,选修
```

上例中 `C010` 与 `C011` 占用同一时间段，但周次区间不重叠（1-8 周 vs 9-16 周），因此**不构成冲突**。

### 7.3 编写规则与校验

- 课程名称、教室中**不要出现英文逗号**；确需使用请用中文顿号或加双引号包裹（解析器支持标准 CSV 引号转义）。
- 数据加载时会校验：编号唯一性、节次顺序、周次范围。校验失败会提示具体行号并以退出码 1 结束。
- 想换成自己班级的课表，复制一份 CSV 改内容即可，用 `--data` 指向它：

```bash
java -cp out timetable.Main all 9 --data data/my_class.csv
```

## 8. 设计与实现要点

完整设计说明见 [docs/DESIGN.md](docs/DESIGN.md)，这里只列出几个关键决策。

**分层与职责**：`model` 只描述数据（`Course` 为不可变对象，构造函数完成字段校验）；`data` 负责把 CSV 变成对象列表；`service` 承载全部查询逻辑，不关心输出格式；`ui` 只做渲染。分层的好处是加一条新命令时，通常只需要在 `service` 加一个方法、在 `ui` 加一个渲染方法、在 `Main` 加一行分发。

**为什么不用集合索引**：课程数量只有几十条，线性扫描的开销可以忽略；用 `List<Course>` 加 `filter` 表达查询意图，代码比维护 `Map<Weekday, List<...>>` 索引更直观，也避免数据变更时索引失效的问题。

**中文等宽对齐**：`TextUtil.width()` 按码点判断东亚宽字符（`0x1100` 以上若干区间）计入 2 列，其余计 1 列；补位时按显示宽度计算而不是字符数，这样"数据结构"和"Go语言与并发编程"在同一列里才会真正居中对齐。表格渲染支持三档对齐和列宽上限，超出上限自动截断加省略号。

**冲突检测算法**：把该周生效的课程按"星期 + 节次"两两比较，节次区间相交判为时间冲突，在此基础上教室相同再判为教室冲突。整体复杂度 O(n²)，n 是该周课程数（20 上下），实测耗时可忽略。

## 9. 常见问题

**Q：运行时提示"课程数据文件不存在"？**
A：命令默认读取当前目录下的 `data/courses.csv`。请在项目根目录执行，或显式指定路径 `--data <绝对路径>`。

**Q：控制台中文变成乱码？**
A：Windows 控制台先执行 `chcp 65001`；或直接使用 `run.bat`，脚本里已经切换过代码页。

**Q：`javac` 报"找不到符号"？**
A：确认在项目根目录执行，并且带了 `-sourcepath src`。若手动逐个编译 `src/timetable/Main.java` 而不加 `-sourcepath`，javac 不会自动寻找同项目下的其它包。

**Q：星期可以写"周一"也可以写"1"吗？**
A：可以。`Weekday.parse()` 同时接受中文全称、中文简写、纯数字以及英文缩写（`MON` / `mon`），解析失败会给出提示并列出合法写法。

**Q：怎么新增一门课？**
A：在 `data/courses.csv` 末尾按格式追加一行，注意编号不要与已有课程重复，保存后重新查询即可，无需修改任何代码。
