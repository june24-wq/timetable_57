# 使用手册

本手册面向使用者，逐条说明 Timetable CLI 的命令、参数、输出含义与常见用法。想了解内部实现请看 [DESIGN.md](DESIGN.md)。

## 1. 安装与运行

### 1.1 环境要求

- JDK 17 或更高版本（`javac -version` 可查看）。
- Windows 下双击 `run.bat` 即可，无需手动配置。

### 1.2 编译

```bash
javac -encoding UTF-8 -sourcepath src -d out src/timetable/Main.java
```

只需指定 `Main.java` 一个入口文件，`-sourcepath src` 会让编译器自动找到并编译它引用的其它 10 个源文件。

Windows 下也可以直接双击 `build.bat`（仅编译）或 `run.bat`（编译并运行）。

### 1.3 运行

```bash
java -cp out timetable.Main <命令> [参数]
```

`run.bat` 的写法是把参数原样透传，因此下面两种方式等价：

```bash
java -cp out timetable.Main day 周四
run.bat day 周四
```

## 2. 全局选项

| 选项 | 作用 | 位置 |
| --- | --- | --- |
| `--data <路径>` | 指定其它课程数据文件（默认 `data/courses.csv`） | 可出现在命令与参数之间的任意位置 |

```bash
java -cp out timetable.Main conflict 9 --data data/courses_conflict_demo.csv
```

参数中**不要**加引号包裹整个命令，路径含空格时才需要加引号。

## 3. 命令一览

| 命令 | 参数 | 作用 |
| --- | --- | --- |
| `help` | 无 | 打印帮助（不带任何参数时也会打印） |
| `all` | `[周次]` | 整周课表网格 |
| `current` | 无 | 当前教学周课表（按系统日期推算） |
| `day` | `<星期> [周次]` | 单日详细课表 |
| `search` | `<关键字> [周次]` | 按课程名 / 教师 / 教室 / 编号模糊搜索 |
| `free` | `<星期> <节次> [周次]` | 查询某时段的空教室 |
| `idle` | `<星期> [周次]` | 统计某天的空闲时段 |
| `conflict` | `[周次]` | 检测时间冲突与教室冲突 |
| `rooms` | 无 | 列出数据中的全部教室 |

所有 `[周次]` 参数省略时，一律使用**当前教学周**。当前教学周由系统日期与学期配置（开学日 2026-09-07、共 16 周）推算得出。

### 4.3 `current` — 当前教学周

```bash
java -cp out timetable.Main current
```

等价于 `all <当前教学周>`，省略了手算周次的麻烦。以系统日期 2026-11-05 为例，输出第 9 周（2026-11-02 ~ 2026-11-08）的课表。

周次推算规则：`(当前日期 - 2026-09-07) / 7 + 1`，再夹到 `1-16`。开学前会按第 1 周显示，超过第 16 周会按第 16 周显示，并在横幅中提示。

### 4.5 `search <关键字> [周次]` — 模糊搜索

java -cp out timetable.Main search C014        # 按课程编号搜
java -cp out timetable.Main search 张伟 1      # 限定在第 1 周搜

- 只在该周生效的课程中搜索，因此第 1 周搜不到第 9 周才开课的选修课。

### 4.8 `conflict [周次]` — 冲突检测

```bash
java -cp out timetable.Main conflict 9
java -cp out timetable.Main conflict 9 --data data/courses_conflict_demo.csv
```

正常数据（无冲突）：

```
════════════════════════════════════════════════════════════════════════════════════════════════════════
 课程冲突检测 · 第 9 周
 2026-2027 学年第一学期　检测范围：该周全部生效课程（已按周次过滤，半学期课程不会误报）
════════════════════════════════════════════════════════════════════════════════════════════════════════
结果：未发现时间冲突或教室冲突，本教学周排课安排合理。
```

演示数据（`courses_conflict_demo.csv`，在正常课表基础上追加 3 门刻意设计的课程）：

```
  [时间冲突] 周二 第1-2节 Web前端开发（信工楼-401，第1-16周）  <->  区块链原理与技术（信工楼-401，第1-16周）
  [教室冲突] 周二 第1-2节 Web前端开发（信工楼-401，第1-16周）  <->  区块链原理与技术（信工楼-401，第1-16周）
  [时间冲突] 周二 第3-4节 操作系统（教1-305，第1-16周）  <->  移动应用开发（机房B-105，第1-16周）

汇总：时间冲突 2 条，教室冲突 1 条，需人工调整排课。
```

两类冲突的含义：

| 类型 | 判定条件 | 说明 |
| --- | --- | --- |
| 时间冲突 | 同一天且节次区间相交 | 一个人无法同时上两门课，通常意味着选课冲突或数据录入错误 |
| 教室冲突 | 时间冲突且教室名称相同 | 同一间教室被两门课同时占用，属于排课事故 |

时间重叠是教室冲突的前提，所以同一对课程可能同时出现在两类里（如上例的第一对）。演示数据中还有一门 `云原生技术` 追加在周四第 9-10 节（与任何课程都不重叠），作为**负样本**，用于验证程序不会误报。

## 5. 输入的容错

| 输入类型 | 接受的写法 | 越界时的真实提示 |
| --- | --- | --- |
| 星期 | `周一` `星期一` `礼拜一` `1` `MON` `mon` | `[参数错误] 无法识别的星期：周八，可写周一至周日` |
| 周次 | `1` ~ `16` | `[参数错误] 周次超出学期范围，应在 1-16 之间，当前为：20` |
| 节次 | `1` ~ `12`（`free` 命令） | `[参数错误] 节次超出范围，应在 1-12 之间，当前为：13` |
| 关键字 | 任意非空字符串 | `[参数错误] search 命令需要给出关键字，例如：search 数据结构` |
| 多余参数 | 会被忽略 | 例如 `day 周一 9 13` 只取 `周一` 和 `9`，`13` 不生效 |
| 数据文件 | 存在的 `.csv` | `[运行失败] 课程数据文件不存在：…（请在项目根目录执行命令，或使用 --data 指定路径）` |

所有错误提示统一以 `[参数错误]` 或 `[运行失败]` 开头，便于肉眼区分；`[参数错误]` 之后还会补印一份帮助表格，避免用户记不住用法：

## 6. 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 运行失败（数据文件缺失、CSV 格式错误、课程编号重复） |
| `2` | 参数错误（未知命令、缺参、数值越界） |

在脚本里可以据此判断：

```bash
java -cp out timetable.Main conflict 9 || echo "排课有问题，需要检查"
```

## 7. 典型场景

### 7.1 上课前快速看今天有什么课

```bash
java -cp out timetable.Main day 周四
```

### 7.2 找一间空教室自习

```bash
java -cp out timetable.Main idle 周四      # 先看哪天、哪几节有空
java -cp out timetable.Main free 周四 9    # 再具体到某节次的空教室
```

### 7.3 选课阶段判断冲突

```bash
# 假设周三第 5-6 节想加一门课，先看自己那时是否已有课
java -cp out timetable.Main day 周三

# 把新课加进 CSV 后，用冲突检测确认没有排课事故
java -cp out timetable.Main conflict 9
```

### 7.4 查某位老师这周给我上几门课

```bash
java -cp out timetable.Main search 张伟
```

### 7.5 整周课表存档

```bash
java -cp out timetable.Main all 9 > week9.txt
```

## 8. 常见问题

**Q：输出中文是乱码怎么办？**
Windows 控制台需要 UTF-8 代码页。`run.bat` 里已内置 `chcp 65001`；若直接用 `java` 命令，请先执行 `chcp 65001`，或使用 Windows Terminal（默认支持 UTF-8）。

**Q：`javac` 报"找不到符号"？**
通常是只编译了 `Main.java` 却没加 `-sourcepath src`。请使用 README 中给出的完整命令。

**Q：周次提示超出范围，但我确实要查第 17 周？**
学期配置为 16 周。若要延长，修改 `Semester.defaultSemester()` 中的 `totalWeeks`，同时确认 `Course` 的周次校验上限（当前为 16）。

**Q：想换成本班的课表？**
只改 `data/courses.csv` 即可，不需要动代码。字段顺序与规则见 [README](../README.md#数据格式说明) 或 `data/courses.csv` 文件头注释。

**Q：`free` 显示某教室空闲，但我去了发现有人在用？**
程序只依据课表数据计算，不含临时借用、考试、社团活动等占用信息。请以现场为准。

**Q：能把课表导入手机日历吗？**
当前版本不支持导出 ICS，已在 `CHANGELOG.md` 的"计划中"列出。欢迎按 [CONTRIBUTING.md](../CONTRIBUTING.md) 的流程提交实现。
